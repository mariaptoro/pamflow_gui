PamFlow Desktop v2.0

1. Abre Anaconda Prompt.
2. Activa tu entorno:
   conda activate pamenv
3. Instala la interfaz moderna una sola vez:
   pip install customtkinter
4. Entra a esta carpeta:
   cd C:\Users\maria.toro\Documents\PamFlowDesktop
5. Ejecuta:
   python app_pamflow.py

Nota: Esta versión ejecuta kedro directamente desde el entorno activo pamenv, sin conda run.
